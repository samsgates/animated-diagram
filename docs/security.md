# Security design

Generated HTML is intended to work without a server.

The framework does not require remote JavaScript, dynamic fetches, `eval`, or
`javascript:` links.

## Adapter trust boundary

The adapter expects upstream HTML generated by a trusted `diagram-design`
workflow.

It does not execute source HTML during compilation.

## Validator

`validateHtml()` reports:

- external script sources
- `javascript:` URLs
- `eval()`
- missing accessibility metadata
- missing reduced-motion CSS
- executable HTML event attributes

A full product embedding untrusted third-party HTML should use a dedicated HTML
sanitizer before calling the adapter.
