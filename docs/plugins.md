# Plugin API

Plugins can transform the graph, compiled plan bundle, or final HTML.

```js
import { definePlugin } from "@animted-diagram/plugins";
import { buildDiagram } from "@animted-diagram/core";

const plugin = definePlugin({
  name: "company-footer",

  transformGraph(graph) {
    return graph;
  },

  transformPlanBundle(bundle) {
    return bundle;
  },

  transformHtml(html) {
    return html.replace("</body>", "<!-- generated by company -->\\n</body>");
  }
});

const result = buildDiagram(spec, {
  plugins: [plugin]
});
```

Hooks execute synchronously and deterministically.

A plugin must not rely on runtime network access if the output needs to remain
self-contained.
