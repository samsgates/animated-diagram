# diagram-design adapter

## Purpose

The adapter adds semantic animation to an HTML file that already contains an
inline SVG generated by `diagram-design`.

## Stable ID requirement

Each connector that should animate needs a stable SVG element ID.

```html
<path id="orders-to-db" d="..." />
```

## Binding file

```json
{
  "edges": {
    "write-order": {
      "pathId": "orders-to-db"
    }
  },
  "nodes": {
    "orders": {
      "elementId": "orders-node"
    }
  }
}
```

The adapter does not alter connector geometry. It inserts a decorative `<use>`
that references the existing path.

## Reverse geometry

If the upstream path data was authored from target toward source:

```json
{
  "edges": {
    "write-order": {
      "pathId": "orders-to-db",
      "reverse": true
    }
  }
}
```

Semantic direction remains `from` to `to`. The binding only corrects the
geometric path orientation.

## Strict mode

By default unresolved edge bindings fail the build.

For exploratory work:

```bash
animated-diagram animate upstream.html \
  --graph graph.json \
  --bindings bindings.json \
  --strict false
```

Production builds should keep strict mode enabled.
